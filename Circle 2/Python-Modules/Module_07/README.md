## Knowledge
### Abstract Class II
In case you try to implement a child class of an abstract class without every abstract method, the object from that class can't be created and therefore the program crashes.
<br>

Some benefits of using abstract classes that way are that by creating a base method, every subclass, here card type, inherits the same functions.<br>
Overall, the code will be clearer to read and easier to understand.
